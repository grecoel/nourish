# NOURISH application data notes — Run 1

## Authoritative inputs

- `data/clean/20_indonesia_district_join_preview.csv` — validated 2025 district snapshot and contextual profile fields.
- `metadata/indonesia_admin_crosswalk.csv` — code-based canonical identity and Kabupaten/Kota display labels.
- `data/analysis/district_priority_persistence.csv` — validated observed-year persistence fields, retained in the app data but not surfaced in Run 1.

`app-data/districts_2025.json` is generated by `npm run data:build`; it must not be hand-edited.

## Analytical constraints

There are 514 district rows. The ranking universe contains 503 districts with valid 2025 PoU and affected-population values. Eleven Jambi district rows do not have valid distinct 2025 PoU values; their PoU and rank fields remain null and they are never imputed.

District identity is stable code plus a human-readable Kabupaten/Kota label; districts sharing a name are not collapsed. PPH, IKP, energy, and protein are contextual non-additive fields. Risk signals, when used later, are risk/odds-ratio-style signals rather than percentages or causal proof.

The longitudinal source has no validated 2024 PoU observation. No longitudinal values are interpolated. No district-level intervention costs are validated, so this prototype does not claim simulated impact or coverage.

Run 3 exposes observed Top-15 year lists only from the validated persistence output. Filled timeline marks mean the district entered the Top 15; 2024 is deliberately absent. Selected risk signals are displayed as source-style signals, not percentages or causal claims.
