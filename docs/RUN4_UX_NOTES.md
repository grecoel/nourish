# Run 4 UX notes

The interface was compacted from an editorial layout into an analytical workspace: header height, page margins, title size, explanatory copy, controls, outcome metrics, and ranking rows were reduced. A consistent sans-serif stack replaces the application’s display-serif treatment. Core controls and ranked rows now appear substantially higher in the viewport.

Atlas remains list-driven because the district geometry precondition was not met. No substitute or fake map was added. Scenario Lab retains its established controls, portfolio, outcomes, and frontier; District Lens retains its comparison and context. The remaining UX limitation is the absence of verified district geometry.
