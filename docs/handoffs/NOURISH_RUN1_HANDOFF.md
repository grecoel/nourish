# NOURISH Run 1 handoff

## Delivered

- A React + TypeScript + Vite prototype in the repository root.
- Product shell with Atlas, Scenario Lab, District Lens, and Policy Options navigation.
- Fully functional Priority Atlas at `/`: live Severity / Scale switching, district search, province filtering, and national rank display.
- Basic District Lens at `/district/:id`, with 2025 metrics, both ranks, rank gap, and a deterministic explanation.
- Application-facing data at `app-data/districts_2025.json`, generated by `scripts/build-app-data.mjs`.

## Repository and authoritative data

Existing validated data sources were retained:

- `data/clean/20_indonesia_district_join_preview.csv` — 2025 district snapshot.
- `metadata/indonesia_admin_crosswalk.csv` — stable codes and Kabupaten/Kota labels.
- `data/analysis/district_priority_persistence.csv` — persistence context retained in generated data for later use.
- `data/raw/policy/` contains locally stored policy PDFs; these were audited but are not used in Run 1 UI.

There was no existing frontend or `package.json`; the simple Vite frontend is newly scaffolded at the repository root.

## Ranking logic and data validation

- Severity rank: descending `pou_pct`.
- Scale rank: descending `undernourished_people`.
- Ties: ascending stable district code.
- The rank universe is all **503** districts with valid 2025 PoU and affected-population values, regardless of UI filter/search state.
- The source includes **514** district rows. The **11** rows without valid 2025 PoU are Jambi districts; they retain null values and are excluded rather than imputed.
- Rank normalization retained for a later Run 2 scenario layer: `(503 - rank) / 502`.
- Kabupaten Bogor (`3201`) and Kota Bogor (`3271`) remain distinct identities. Mamberamo Raya (`9120`) is retained with its validated 2025 data.
